## 1. 硬件平台与总体架构

- **主控模组**：ESP32-WROOM-32E (Xtensa® 双核 32 位 LX6，240 MHz，4MB SPI Flash)。
- **电源总线**：外部 12V / 5A (60W) DC 开关电源总线，主板内置降压 LDO 供给 ESP32 及传感器 3.3V 逻辑电平。
- **功率执行回路**：8 路独立 N 沟道 60V $V_{DS}$ MOS 管（低边受控接地通断，高电平导通，开机下拉预置）。
- **传感器与人机接口网络**：
  - **I2C 传感器总线 (SDA=IO21, SCL=IO22)**：并联 AHT25（地址 `0x38`，上层雨林空气温湿度）+ BH1750（地址 `0x23`，环境照度）。
  - **1-Wire 单总线 (IO4)**：DS18B20 接触式水下/贴片探头（贴于守宫热区天然页岩板底面，监测腹部传导热）。
  - **数字开关量输入 (IO14)**：磁敏干簧管开关（前挡玻璃防逃逸门禁，开启芯片内部弱上拉，常开触点对地闭合）。
  - **模拟输入 (IO34)**：ADC1_CH6（原土壤湿度接口，纯输入引脚，硬件保留备用，当前闲置）。
  - **人机交互接口**：板载状态呼吸指示灯 (IO23) + 板载 Boot 按键 (IO0)。

## 3. 剩余可用 GPIO 资源清单与扩展指引

在满足生态箱 8 路功率执行器、双温双湿环境网络、接触式腹热监控、防逃逸干簧管门禁、指示灯和串口之后，ESP32 排针上剩余的 GPIO 资源整理如下：

| 引脚编号 | 引脚物理特性 | 硬件约束与使用注意事项 | 推荐拓展用途与设计指引 |
| :--- | :--- | :--- | :--- |
| **GPIO 32** | 双向通用 I/O | 纯净安全，支持硬件 LEDC PWM 输出 | **首选推荐：4-Pin 风扇 25kHz PWM 调速输入 (Pin 4)**<br>可直接输出 3.3V TTL PWM 信号线性调节排气风量 |
| **GPIO 35** | 纯输入 (GPI) | ADC1_CH7 / **无芯片内部弱上拉或下拉电阻** | **首选推荐：4-Pin 风扇 TACH 转速脉冲测速 (Pin 3)**<br>必须外接 4.7kΩ~10kΩ 电阻上拉至 3.3V（严禁接 12V！） |
| **GPIO 13** | 双向通用 I/O | ADC2_CH4 / HSPI_MOSI / 触摸输入<br>注：Wi-Fi 运行时不可用作 ADC2，作数字 IO 正常 | **自由可用**：如外接微型有源蜂鸣器（超温/逃逸告警）、外接 SPI/I2C 微型 OLED 显示屏 |

| **GPIO 39 (SENSOR_VN)** | 纯输入 (GPI) | ADC1_CH3 / 内部无上拉或下拉电阻 | **自由可用**：扩展第二路模拟传感器输入（如微型紫外线传感器、水槽液位探头） |

| **GPIO 15 (MTDO)** | Strapping 引脚 | 开机默认控制 U0TXD 调试信息静音（默认拉高） | 可用作普通输出，注意启动电平特征 |

## 4. 外设接口与执行回路设计规范

### 4.1 8 路 MOS 管低边开关生态角色分配
全部 8 路 MOS 采用低边开关（Low-Side Switch），负载正极接 +12V DC，负极接 MOS 漏极（Drain）。

| MOS 通道 | 控制引脚 (GPIO) | 额定电压 / 功率 | 对应生态箱执行器 | 安全硬限制 (Safety Envelope) |
| :---: | :---: | :---: | :--- | :--- |
| **MOS 1** | **GPIO 19** | 12V / ~3W | **积水凤梨叶心定时给水蠕动泵 #1** | 单次注水强制上限 $\le 20\text{s}$，防植物淹死 |
| **MOS 2** | **GPIO 18** | 12V / ~3W | **豹纹守宫饮水盆定量给水蠕动泵 #2** | 单次注水强制上限 $\le 12\text{s}$，防溢水破坏下层干燥 |
| **MOS 3** | **GPIO 17** | 12V / ~6W | **守宫热区 12V PTC 40℃ 物理自限温加热片** | **$\ge 35.0^\circ\text{C}$ 固件硬熔断强制切断**；正常滞环 31.0~32.2℃ |
| **MOS 4** | **GPIO 16** | 12V / 15W | **干湿隔层中层 12V 大面积柔性辅助加热板** | 单次持续工作上限 $\le 30\text{min}$，AHT25 控温 (24.0~26.5℃) |
| **MOS 5** | **GPIO 33** | 12V / ~4W | **外挂 12V 微孔超声波冷雾模块电源** | **单次持续上限 $\le 10\text{s}$，触发后强制 15 分钟锁定防抖** |
| **MOS 6** | **GPIO 25** | 12V / ~2.5W| **上层雨林利民 TL-C12C 抽湿/换气风扇主供电** | 单次强排上限 $\le 90\text{s}$；上层 RH>88% 自动触发 45s |
| **MOS 7** | **GPIO 26** | 12V / 10W | **箱顶全光谱植物补光主灯** | 支持定时通断或常开常关 |
| **MOS 8** | **GPIO 27** | 12V | **通用功率冗余预留通道 (Spare)** | 自由调用 |

### 4.2 超声波雾化回路硬件专项说明
- **严禁直连裸片**：微孔雾化钢片属于高 Q 值压电陶瓷容性负载，需 108kHz 交流高频共振且交流峰峰值需达 40~80V。直流 12V 直连会导致损坏且不出雾。
- **接线方案**：
  - 选用市售成熟的 **12V 微孔雾化驱动板模块**（含 108kHz 扫频振荡 IC、高频升压工字电感与阻抗匹配电容）。
  - **驱动模块电源正极（VCC）** $\to$ 箱体 **+12V DC 总线**。
  - **驱动模块电源负极（GND）** $\to$ 主板 **MOS 5 漏极端子（GPIO 33）**。
  - **驱动模块高频输出端** $\to$ 沉木接水盆底部的 108kHz 16mm/20mm 微孔雾化片。
- **气动冷雾输送（气水解耦）**：
  - 微孔雾化片产生 3~5 微米超微干冷雾，通过微型 3010 鼓风机注入微正压，气雾经 10mm 硅胶管送入箱顶鸭嘴出风口。
  - 断电瞬间微孔毛细自锁，100% 杜绝残压滴水。

## 5. 固件逻辑重构与接口规范

### 5.1 废除原工程自动浇花任务
- 原工程在 `status_timer_cb` 中定期调用 `check_auto_water()`，以 ADC1 (GPIO34) 土壤湿度作为触发条件翻转 MOS 1。
- **本工程变更**：
  - 彻底移除 `check_auto_water()` 逻辑。
  - 保留底层的 `/change_relay1` ~ `/change_relay8` 通用调试接口及 `/api/sensors` 兼容接口。
  - 将自治生命维持逻辑交由独立的 FreeRTOS 任务 `vivarium_closed_loop_task` 处理。

### 5.2 本地自治保护任务 (`vivarium_closed_loop_task`)
无论网络是否连通、Agent 是否在线，ESP32 内部每秒执行安全巡检：
1. **守宫腹热安全闭环（DS18B20 -> MOS 3）**：
   - 目标区间：$31.0^\circ\text{C} \sim 32.2^\circ\text{C}$；
   - **超温熔断**：$T_{slab} \ge 35.0^\circ\text{C}$ 时强制切断 MOS 3 并报警；
   - **探头掉线保护**：若读取异常（值 $\le 0^\circ\text{C}$ 或 $\ge 80^\circ\text{C}$），强制切断 MOS 3。
2. **隔层大环境温控（AHT25 温度 -> MOS 4）**：
   - 当 $T_{rainforest} < 24.0^\circ\text{C}$ 时启动 MOS 4；当 $T_{rainforest} \ge 26.5^\circ\text{C}$ 时关闭 MOS 4。
3. **上层雨林高湿排风保护（AHT25 湿度 -> MOS 6）**：
   - 当 $RH > 88\%$ 时启动风扇排湿 45 秒。
4. **定时微对流防闷**：
   - 连续无排风达到 3 小时，强制启动风扇微换气 30 秒。

### 5.3 三段式 LLM Agent API 与通配符路由
启用 `config.uri_match_fn = httpd_uri_match_wildcard`， Handler 总数控制在 15/16：
1. **遥测接口**：`GET /api/v1/telemetry`
   - 返回分立双温双湿、照度、干簧管状态、8路 MOS 实时布尔值与底层继电器数组。
2. **配置接口**：`GET / POST /api/v1/config`
   - 读取/热配生态参数（热区上下限、排湿门限、防闷间隔），持久化存入 NVS。
3. **安全动作单句柄通配符**：`POST /api/v1/actuator/*`
   - `/api/v1/actuator/mist?duration_s=5`（微孔冷雾，带 15 分钟防抖与 $\le 10\text{s}$ 硬截断）
   - `/api/v1/actuator/gecko_water?duration_s=6`（守宫补水，$\le 12\text{s}$ 硬截断）
   - `/api/v1/actuator/bromeliad_water?duration_s=10`（凤梨补水，$\le 20\text{s}$ 硬截断）
   - `/api/v1/actuator/bulk_heat?duration_s=600`（隔层加热，$\le 1800\text{s}$ 硬截断）
   - `/api/v1/actuator/vent?duration_s=30`（风扇排风，$\le 90\text{s}$ 硬截断）
   - `/api/v1/actuator/light`（顶置补光灯开启）

## 6. TODO：4-Pin 风扇 25kHz PWM 调速与 TACH 测速 (扩展预留)

> 作为后续风道精确静音与流场调控的开发技术备忘录，当前版本固件直接通过 MOS 6 控制风扇 12V 启停，后续按需启用。

1. **PWM 调速控制**：规划使用 **GPIO 32**
   - 使用 ESP32 硬件 `LEDC` 外设，输出标准 **25 kHz** PWM 载波，8-bit 占空比分辨率（0~255）。
   - ESP32 输出的 3.3V 高电平完全高于 Intel 规范的 2.0V 判定门限，可直接直连风扇 Pin 4。
2. **TACH 转速反馈采集**：规划使用 **GPIO 35**
   - 风扇 Pin 3 为集电极/漏极开路输出，**必须通过 4.7kΩ~10kΩ 电阻上拉至 ESP32 的 3.3V（严禁上拉到 12V！）**。
   - 使用 GPIO 双边沿中断或硬件脉冲计数器 (`pcnt`) 采集脉冲数（每转产生 2 个脉冲，公式：$\text{RPM} = \frac{\text{脉冲数}}{2} \times 60$）。
3. **软硬件协同停转保护**：
   - 部分风扇在 0% PWM 下仍保持最低保底转速，需切断 MOS 6 供电才能彻底静音停转。
   - 在切断风扇低边电源时，需同步拉低 PWM 输出并屏蔽 TACH 脉冲计数，避免悬空电平干扰。
