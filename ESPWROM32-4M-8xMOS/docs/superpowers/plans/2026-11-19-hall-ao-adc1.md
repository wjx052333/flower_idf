# 49E 霍尔传感器 AO 接入 GPIO 36 与 Web 折线图渲染实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 49E 线性霍尔传感器的 AO 模拟量信号接入 ESP32 的 GPIO 36 (ADC1_CH0)，在固件中完成 ADC 采样与 `/api/sensors` 数据透传，并在 Web 控制面板中增加数值卡片与实时折线图。

**Architecture:** ESP32 利用原生不受 Wi-Fi 干扰的 ADC1 通道 0 采集 0~4095 原始计数，将结果放入全局 `sensor_cache_t`，通过 `/api/sensors` JSON 接口透传。前端页面通过 Chart.js 实时渲染折线图并展示数值卡片。

**Tech Stack:** ESP-IDF v6 (C99, `adc_oneshot`), HTML5, JavaScript (ES6), Chart.js (v4.4.1).
