## 1. 硬件平台与模组架构概述

- **主控模组**：ESP32-WROOM-32E (Xtensa® 双核 32 位 LX6 微处理器，最高主频 240 MHz)。
- **存储配置**：集成 4MB SPI Flash（通过内部 GPIO6~GPIO11 连接），无集成外部 PSRAM。
- **排针引出**：模组所有外部可用 IO 均已通过 2.54mm 排针引出。
- **功率执行器**：8 路独立 N 沟道功率 MOS 管（漏源耐压 $V_{DS} = 60\text{V}$，低边开关驱动 Low-Side Switch）。**全部 8 路均对等开放，作为通用功率回路（可接 12V 机箱风扇、电磁阀、水泵、补光灯等）**。
- **人机交互接口**：1 个板载用户 LED，1 个板载 Key（GPIO0 / Boot）。
- **传感器与外设总线**：
  - I2C 总线：**BH1750** 照度传感器（`0x23`）+ **AHT25** 空气温湿度传感器（`0x38`）
  - 单端模拟输入：土壤湿度传感器（ADC1）
  - 1-Wire 单总线：水温传感器（DS18B20）
  - 数字开关量输入：机箱盖螺丝-铜箔触点（盖板装配到位检测，见 3.2）

## 3. 外设接口与 8 路 MOS 管设计规范

### 3.1 8 路 MOS 管低边开关与通用 HTTP 控制设计
- **硬件特性**：全部 8 路低边驱动采用 60V $V_{DS}$ N 沟道功率 MOS 管，推挽驱动栅极。
- **电平逻辑**：GPIO 输出高电平（1 / 3.3V）导通闭合；GPIO 输出低电平（0 / 0V）截止断开。
- **开机安全**：上电时主控在配置 GPIO 方向前，先将 8 个引脚预置为低电平并使能内部下拉，避免上电浮空误开通。
- **功能对等与通用性**：
  - 代码中不限定任何一路 MOS 的特定业务用途（例如 12V 机箱风扇的主供电线可自由接在 MOS1~MOS8 任一路输出端子上）。
  - 参考 `relay_four` 架构，全部 8 路 MOS 均导出标准的 HTTP URL 接口：
    - `GET /change_relay{N}`：开启第 N 路（默认 10 秒后自动关断）
    - `GET /change_relay{N}?duration=30000`：开启第 N 路（指定 30 秒后自动关断）
    - `GET /change_relay{N}?action=off`：手动关闭第 N 路
    - （其中 $N \in [1, 8]$）
  - `/api/sensors` 接口在保留原有全部传感器字段（`humidity`, `temperature`, `lux`, `strategy` 等）的同时，输出全部 8 路继电器的当前运行状态数组 `relays`。

### 3.2 机箱盖螺丝到位检测 (螺丝-铜箔触点)
取代原磁敏干簧管方案：不依赖磁铁安装，且螺丝没拧到位时立即可知。

- **引脚分配**：**GPIO 14**。
- **检测原理**：
  - 一片铜箔用绝缘胶带浮空固定在机箱外盖固定螺丝孔的后方（螺丝尖端行进路径上），铜箔经导线接 **GPIO 14**。
  - 螺丝拧紧时，螺丝尖端压触铜箔，将 GPIO 14 拉到 GND → 读到低电平（0，**盖板到位**）。
  - 螺丝松开或取下，铜箔脱离接触，GPIO 14 被上拉到 3.3V → 读到高电平（1，**盖板未装好**）。
  - 电平逻辑与原干簧管一致（0 = 到位，1 = 未到位），固件读取逻辑、`/api/sensors` 的 `"reed"` 字段（1 = 到位）及 UVB 互锁逻辑无需改变；仅 Web 页面标签“干簧管 [IO14]”建议后续改为“盖板螺丝 [IO14]”。
- **机械安装要点**：
  - 铜箔**背面和四周边缘**均需用绝缘胶带（聚酰亚胺/PVC）包覆，只在螺丝尖端接触处留出裸露窗口；铜箔绝不能碰到机箱金属，否则永远读为“到位”。
  - 铜箔位置按“螺丝拧到底才接触”设定：M3 螺距 0.5 mm，建议铜箔表面与拧紧后螺丝尖端的间隙在松开约 1 圈（0.5 mm）时即脱离接触；铜箔背后垫一层薄泡棉增加接触压力与容差。
  - 铜箔建议选用镀锡/镀镍铜箔（纯铜易氧化使接触电阻变大）；导线焊在铜箔非接触区并做应力释放。
  - 导线尽量短（≤15 cm），远离 MOS 输出、风扇、水泵、电磁阀等大电流/感性负载线缆。
- **螺丝如何接 GND**（螺丝本身必须是一条低阻接地通路，二选一）：
  - **方案 A：金属机箱搭铁（推荐）**：机箱底壳与外盖均为金属时，将底壳通过一根导线 + 环形端子接到电路板 **GND**（建议接在 12V 电源负极入口/信号 GND 同一点，单点接地，避免大电流 MOS 回路流经机箱）。外盖螺丝经外盖/底壳螺纹构成接地通路。注意：阳极氧化、喷漆表面须刮除，螺丝垫片使用带齿星形垫圈，保证螺纹处接触电阻 < 0.5 Ω。
  - **方案 B：塑料机箱 + 铜柱接地**：螺丝拧入固定在底壳内的黄铜螺母/铜柱（或铜嵌件），铜柱用导线焊接/环形端子接到 PCB 的 **GND** 焊盘。螺丝头不外露带电，仅作为地的延伸。
  - 无论哪种方案：**机箱不得接市电 PE**（本系统为 12V 低压隔离供电，机箱仅与系统 GND 单点相连，避免地环路）；螺丝、铜箔以外的任何金属件不得意外短接 GPIO 14。
  - 判据：螺丝拧紧时铜箔对 GND 的总接触电阻（螺丝-铜箔界面 + 螺丝到 GND 通路）应 ≤ 100 Ω。LED 支路约 4.3mA 流过该电阻，铜箔电位须低于 VIL（0.25×VDD ≈ 0.825V），对应上限约 190 Ω，留一倍余量；接触不良时 LED 会变暗，可直观发现。
- **悬浮 IO 的 ESD / 抗干扰保护（不改 PCB，飞线小件方案）**：
  铜箔位于机箱内部，外部可触摸的金属只有已接地的螺丝，静电主要走螺丝入地，铜箔受直接放电的风险很小；主要风险是高阻悬浮节点耦合的噪声和偶发尖峰，ESP32 引脚自带约 2kV HBM 防护。因此**不设 TVS 等过度设计**，只用插件分立件做一个串在导线上的小件，焊在 GPIO 14 / 3.3V / GND 排针端子上，用热缩管或小块洞洞板固定。

  ```
                      3.3V ───┬───────────────┐
                              │               │
                           [R2 10kΩ]      [R3 330Ω]
                              │               │
                              │          [LED 红/黄/绿] ← 门关紧指示（阳极在上）
                              │               │
   铜箔 ──(导线≤15cm)─────────┴───────┬───────┘
                                      │
                                    [R1 1kΩ]
                                      │
                                      ├──────────── GPIO 14 排针
                                    [C1 100nF]
                                      │
                                     GND
   螺丝 ── 机箱/铜柱 ── GND
  ```

  | 元件 | 参数 | 作用 |
  | :--- | :--- | :--- |
  | **R1 串联电阻** | 1kΩ 色环/插件电阻 | 限制尖峰电流，与 C1 构成约 100µs 低通（**不是 LED 限流电阻**） |
  | **C1 滤波电容** | 100nF 瓷片电容（X7R），GPIO 14 对 GND | 吸收尖峰，兼做硬件去抖 |
  | **R2 外部上拉** | 10kΩ 到 3.3V 排针 | 螺丝松开时 LED 支路不导通，R2 保证悬浮节点为 ~10kΩ 低阻高电平，抗耦合干扰；焊在铜箔侧（R1 之前） |
  | **LED + R3** | 红/黄/绿 LED（Vf≈2V）+ 330Ω，3.3V → R3 → LED → 铜箔 | **门关紧指示灯**：螺丝拧紧触碰铜箔时电流经螺丝入地，LED 点亮；松开即熄灭 |

  - **LED 指示灯为纯硬件实现**：不占用 GPIO，不依赖固件，LED 状态与 GPIO 14 读数完全一致（亮 = 到位 = 低电平）。蓝/白 LED（Vf≈3V）在 3.3V 下余量不足，不要使用。
  - LED 支路须接在铜箔侧（R1 之前），这样 GPIO 14 经 R1 直接看到铜箔电位，不受 LED 压降影响。
  - 螺丝触点电流 ≈ (3.3V − 2V) / 330Ω ≈ 4mA（加 R2 的 0.33mA），该小电流可冲刷触点氧化层，使接触更可靠；接触电阻升高时 LED 变暗，可作为接触不良的直观提示。
  - LED 如需安装在机箱外壳，用双绞线引出并同样保持短线，远离大电流线。
  - 固件中仍使能内部上拉（`GPIO_PULLUP_ENABLE`），与 R2 并联。
  - 螺丝接触时 GPIO 14 经 R1 接近 0V（< 0.825V，满足 VIL）；释放时 RC 上升约 1 ms，不影响检测。
  - 如后续发现误触发，可在铜箔导线上另外跨接插件 TVS（如 SMF3.3CA）或现成 ESD 保护小板作为加强；当前不要求。
  - 铜箔导线远离 MOS 输出、风扇、水泵、电磁阀线缆；12V 感性负载两端并联续流二极管。
- **洞洞板制作（不打 PCB，一块约 2×3cm 单面洞洞板即可）**：
  - **物料**：洞洞板 1 块；1kΩ、10kΩ、330Ω 插件电阻各 1 只；100nF 瓷片电容 1 只；红/黄/绿 LED（φ3 或 φ5）1 只；2.54mm 排针/杜邦线若干（3 根接 ESP32：3V3、GND、GPIO 14；1 根接铜箔）。
  - **网络表**（按此连接，节点名在板上用焊锡/裸铜线连成一片）：

    | 节点 | 连接的元件引脚 |
    | :--- | :--- |
    | **3V3** | R2 一端、R3 一端、杜邦线 → ESP32 3V3 排针 |
    | **GND** | C1 一端、杜邦线 → ESP32 GND 排针 |
    | **FOIL** | R2 另一端、LED **负极(短脚)**、R1 一端、杜邦线/导线 → 铜箔 |
    | **PIN** | R1 另一端、C1 另一端、杜邦线 → ESP32 GPIO 14 排针 |
    | （LED 内部） | R3 另一端 → LED **正极(长脚)** |

  - **参考布局**（俯视，每格一个孔位，横线为板背面焊接连线）：

    ```
            列1    列2    列3    列4    列5    列6
     行1   [3V3]━━━━●━━━━━━━━●━━━━━━━━━━━━━━━━━      ← 3V3 轨
                    R2      R3(330Ω)
     行2            │       │
     行3            │      LED(▼ 正极在上)
     行4   [FOIL]━━━●━━━━━━━●━━━━━━━●━━━━━━━━━      ← FOIL 轨 (接铜箔)
                                    R1(1kΩ)
     行5                            │
     行6                            ●━━[PIN]         ← PIN (接 GPIO 14)
                                    C1(100nF)
     行7   [GND]━━━━━━━━━━━━━━━━━━━━●━━━━━━━━━      ← GND 轨
    ```

  - **制作要点**：
    - 四个对外接口（3V3、GND、GPIO 14、铜箔）用杜邦母头线或排针引出，GPIO 14 线与铜箔线分开走线。
    - LED 若要装到外壳上：LED 引脚各接一根双绞线引出，板上留 LED 两个焊盘即可；注意正负极不要接反。
    - 焊完后用热缩管或热熔胶固定，整块小板放在机箱内、远离 MOS 输出和风扇线。
    - **上电前用万用表通断档确认**：3V3 与 GND 之间不通（无短路）；FOIL 与 GND 不通（铜箔未碰机箱）；FOIL 与 PIN 之间约 1kΩ。
    - **上电测试**：螺丝松开时 LED 熄灭，GPIO 14 读 1；螺丝拧紧时 LED 亮，GPIO 14 读 0。若螺丝拧紧后 LED 很暗或不亮，优先检查螺丝到 GND 的通路和铜箔接触。
- **固件注意事项**（本次仅更新硬件文档，固件未修改，后续建议）：
  - 螺丝缓慢拧入/松开及接触不稳时会产生抖动，GPIO 14 中断后应增加 20~50ms 软件去抖，再确认电平变化。
  - 启动时读取一次 GPIO 14，若为高电平直接判定“盖板未装好”，并保持 UVB 等互锁通道关断（沿用现有“先断电再核对”的互锁逻辑）。
  - 支持配置 GPIO 下降沿/上升沿中断进行实时告警与状态采集。

### 3.3 AHT25 空气温湿度传感器与 I2C 总线复用
- **总线复用**：与 BH1750 照度传感器共享 **SDA = GPIO 21, SCL = GPIO 22**。
- **从机地址完全隔离**：
  - BH1750 照度传感器：`0x23`
  - AHT25 温湿度传感器：`0x38`
- **兼容性**：两者均为 3.3V 逻辑电平，均支持 400kHz Fast 模式，总线仅需一组 4.7kΩ 上拉电阻即可稳定并联工作。

### 5.1 调速背景与 Intel 规范
台式机 4-Pin 风扇接口线序：
- Pin 1: GND（负极，可接 MOS 板受控输出）
- Pin 2: +12V（外置 12V 电源正极）
- Pin 3: TACH（转速脉冲反馈，开漏输出）
- Pin 4: PWM（调速输入，Intel 规范频率 25 kHz，电平兼容 3.3V TTL）

### 5.2 待实现规划引脚
- **PWM 调速控制**：规划使用 **GPIO 32**
  - 使用 ESP32 硬件 `LEDC` 外设，输出标准 **25 kHz** PWM 载波，8-bit 占空比分辨率（0~255）。
  - ESP32 输出的 3.3V 高电平完全高于 Intel 规范的 2.0V 判定门限，可直接直连风扇 Pin 4。
- **TACH 转速反馈采集**：规划使用 **GPIO 35**
  - 风扇 Pin 3 为集电极/漏极开路输出，**必须通过 4.7kΩ~10kΩ 电阻上拉至 ESP32 的 3.3V（严禁上拉到 12V！）**。
  - 使用 GPIO 双边沿中断或硬件脉冲计数器 (`pcnt`) 采集脉冲数（每转产生 2 个脉冲，公式：$\text{RPM} = \frac{\text{脉冲数}}{2} \times 60$）。
- **软硬件协同停转保护**：
  - 部分风扇在 0% PWM 下仍保持最低保底转速，需切断 MOS 电源才能彻底静音停转。
  - 在切断风扇低边电源时，需同步拉低 PWM 输出并屏蔽 TACH 脉冲计数，避免悬空电平干扰。
