## 1. 硬件平台与模组架构概述

- **主控模组**：ESP32-WROOM-32E (Xtensa® 双核 32 位 LX6 微处理器，最高主频 240 MHz)。
- **存储配置**：集成 4MB SPI Flash（通过内部 GPIO6~GPIO11 连接），无集成外部 PSRAM。
- **排针引出**：模组所有外部可用 IO 均已通过 2.54mm 排针引出。
- **功率执行器**：8 路独立 N 沟道功率 MOS 管（漏源耐压 $V_{DS} = 60\text{V}$，低边开关驱动 Low-Side Switch）。**全部 8 路均对等开放，作为通用功率回路（可接 12V 机箱风扇、电磁阀、水泵、补光灯等）**。
- **人机交互接口**：1 个板载用户 LED，1 个板载 Key（GPIO0 / Boot）。
- **传感器与外设总线**：
  - I2C 总线：**BH1750** 照度传感器（`0x23`）+ **AHT25** 空气温湿度传感器（`0x38`）
  - 单端模拟输入：土壤湿度传感器（ADC1）
  - 1-Wire 单总线：水温传感器（DS18B20）
  - 数字开关量输入：磁敏干簧管（门禁/开合检测）

## 3. 外设接口与 8 路 MOS 管设计规范

### 3.1 8 路 MOS 管低边开关与通用 HTTP 控制设计
- **硬件特性**：全部 8 路低边驱动采用 60V $V_{DS}$ N 沟道功率 MOS 管，推挽驱动栅极。
- **电平逻辑**：GPIO 输出高电平（1 / 3.3V）导通闭合；GPIO 输出低电平（0 / 0V）截止断开。
- **开机安全**：上电时主控在配置 GPIO 方向前，先将 8 个引脚预置为低电平并使能内部下拉，避免上电浮空误开通。
- **功能对等与通用性**：
  - 代码中不限定任何一路 MOS 的特定业务用途（例如 12V 机箱风扇的主供电线可自由接在 MOS1~MOS8 任一路输出端子上）。
  - 参考 `relay_four` 架构，全部 8 路 MOS 均导出标准的 HTTP URL 接口：
    - `GET /change_relay{N}`：开启第 N 路（默认 10 秒后自动关断）
    - `GET /change_relay{N}?duration=30000`：开启第 N 路（指定 30 秒后自动关断）
    - `GET /change_relay{N}?action=off`：手动关闭第 N 路
    - （其中 $N \in [1, 8]$）
  - `/api/sensors` 接口在保留原有全部传感器字段（`humidity`, `temperature`, `lux`, `strategy` 等）的同时，输出全部 8 路继电器的当前运行状态数组 `relays`。

### 3.2 磁敏干簧管开关 (门禁 / 盖子开合检测)
- **引脚分配**：**GPIO 14**。
- **接线方案**：
  - 干簧管一端接 **GPIO 14**。
  - 干簧管另一端直接接 **GND**。
- **设计理由**：
  - **无需外置电阻**：ESP32 的 GPIO 14 内部自带弱上拉（~45kΩ），开启 `GPIO_PULLUP_ENABLE` 即可。
  - 磁铁靠近时触点吸合接地，GPIO 14 读到低电平（0，代表**闭合**）；磁铁远离断开时读到高电平（1，代表**断开**）。
  - **UI 状态展示**：Web 控制页面传感器数据栏已集成展示“干簧管 [IO14]”实时开闭状态（“闭合”显示绿色，“断开”显示浅红）；`/api/sensors` JSON 响应中新增 `"reed": 1/0` 字段。
  - 支持配置 GPIO 下降沿/上升沿中断进行实时告警与状态采集。

### 3.3 AHT25 空气温湿度传感器与 I2C 总线复用
- **总线复用**：与 BH1750 照度传感器共享 **SDA = GPIO 21, SCL = GPIO 22**。
- **从机地址完全隔离**：
  - BH1750 照度传感器：`0x23`
  - AHT25 温湿度传感器：`0x38`
- **兼容性**：两者均为 3.3V 逻辑电平，均支持 400kHz Fast 模式，总线仅需一组 4.7kΩ 上拉电阻即可稳定并联工作。

## 4. 剩余可用 GPIO 资源清单

在完成 8 路 MOS、板载 LED、Key、双设备 I2C、双温度、土壤湿度、干簧管分配后，排针上剩余的 GPIO 资源整理如下：

| 引脚编号 | 引脚类型 | 特性描述 | 推荐用途 |
| :--- | :--- | :--- | :--- |
| **GPIO 32** | 双向通用 I/O | 安全纯净，支持硬件 LEDC / PWM | **预留给 4-Pin 风扇 PWM 调速** |
| **GPIO 35** | 纯输入 (GPI) | ADC1_CH7 / 无内部上拉 | **预留给 4-Pin 风扇 TACH 转速测速 (需外接 4.7k 上拉到 3.3V)** |
| **GPIO 13** | 双向通用 I/O | ADC2_CH4 / HSPI_MOSI | 自由可用（如蜂鸣器、扩展 SPI 屏） |
| **GPIO 36 (VP)** | 纯输入 (GPI) | ADC1_CH0 | 自由可用（如分压测量 12V 供电电压） |
| **GPIO 39 (VN)** | 纯输入 (GPI) | ADC1_CH3 | 自由可用（扩展模拟输入） |
| **GPIO 12, 2, 5, 15**| Strapping 引脚 | 受开机电平约束 | **严禁在 GPIO 12 上接上拉！** 其余引脚仅作辅助输出 |

## 5. TODO：4-Pin 风扇 PWM 调速与 TACH 测速 (待后续实现)

> 本章节作为后续功能扩展的开发技术备忘录，当前版本固件暂不启用，后续按需实现。

### 5.1 调速背景与 Intel 规范
台式机 4-Pin 风扇接口线序：
- Pin 1: GND（负极，可接 MOS 板受控输出）
- Pin 2: +12V（外置 12V 电源正极）
- Pin 3: TACH（转速脉冲反馈，开漏输出）
- Pin 4: PWM（调速输入，Intel 规范频率 25 kHz，电平兼容 3.3V TTL）

### 5.2 待实现规划引脚
- **PWM 调速控制**：规划使用 **GPIO 32**
  - 使用 ESP32 硬件 `LEDC` 外设，输出标准 **25 kHz** PWM 载波，8-bit 占空比分辨率（0~255）。
  - ESP32 输出的 3.3V 高电平完全高于 Intel 规范的 2.0V 判定门限，可直接直连风扇 Pin 4。
- **TACH 转速反馈采集**：规划使用 **GPIO 35**
  - 风扇 Pin 3 为集电极/漏极开路输出，**必须通过 4.7kΩ~10kΩ 电阻上拉至 ESP32 的 3.3V（严禁上拉到 12V！）**。
  - 使用 GPIO 双边沿中断或硬件脉冲计数器 (`pcnt`) 采集脉冲数（每转产生 2 个脉冲，公式：$\text{RPM} = \frac{\text{脉冲数}}{2} \times 60$）。
- **软硬件协同停转保护**：
  - 部分风扇在 0% PWM 下仍保持最低保底转速，需切断 MOS 电源才能彻底静音停转。
  - 在切断风扇低边电源时，需同步拉低 PWM 输出并屏蔽 TACH 脉冲计数，避免悬空电平干扰。
