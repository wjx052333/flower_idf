## 1. 硬件平台与模组架构概述

- **主控模组**：ESP32-WROOM-32E (Xtensa® 双核 32 位 LX6 微处理器，最高主频 240 MHz)。
- **存储配置**：集成 4MB SPI Flash（通过内部 GPIO6~GPIO11 连接），无集成外部 PSRAM。
- **排针引出**：模组所有外部可用 IO 均已通过 2.54mm 排针引出。
- **功率执行器**：8 路独立 N 沟道功率 MOS 管（漏源耐压 $V_{DS} = 60\text{V}$，低边开关驱动 Low-Side Switch）。
- **人机交互接口**：1 个板载用户 LED，1 个板载 Key（GPIO0 / Boot）。
- **外部传感器总线**：
  - 照度传感器：BH1750（I2C 总线）
  - 土壤湿度传感器：电容式模拟输出（单端 ADC 模拟采样）
  - 温度传感器：DS18B20（单总线 1-Wire 协议）

## 3. 传感器与外设电路设计规范

### 3.1 照度传感器 (BH1750 I2C)
- **引脚分配**：`SDA -> GPIO 21`，`SCL -> GPIO 22`。
- **设计理由**：GPIO 21 / 22 为经典 ESP32 默认的标准硬件 I2C 引脚，硬件外设支持极佳，时序稳定，与开源生态及 ESP-IDF 原生驱动完全兼容。
- **硬件要求**：
  - 传感器模块通常板载 4.7kΩ 上拉电阻到 3.3V；若使用裸片，需在 SDA 和 SCL 线上各增加一颗 4.7kΩ 上拉至 3.3V。
  - BH1750 的 ADDR 引脚接地（GND），对应 I2C 设备地址为 `0x23`。

### 3.2 土壤湿度传感器 (模拟量 ADC)
- **引脚分配**：`ADC 输入 -> GPIO 34 (ADC1 通道 6)`。
- **关键设计考量（Wi-Fi 兼容性）**：
  - **ESP32 硬件限制**：当 Wi-Fi 功能启动工作时，**ADC2 会被 Wi-Fi 射频子系统独占**，所有 ADC2 引脚无法用于应用层模拟转换。因此土壤湿度检测**必须使用 ADC1**。
  - GPIO 34 属于 ADC1 通道（ADC1_CH6），且为纯输入引脚（GPI，无数字输出电路），不浪费数字输出功能，是模拟采样的最优选。
- **电平配置**：
  - 采样衰减配置为 `ADC_ATTEN_DB_12`（满量程输入电压约 0 ~ 3.3V）。

### 3.3 水温 / 土壤温度传感器 (DS18B20 1-Wire)
- **引脚分配**：`1-Wire DQ -> GPIO 4`。
- **设计理由**：
  - DS18B20 采用 1-Wire 单总线协议，主控需在同一总线上进行电平拉低和释放输入读取，因此引脚**必须具备双向数字 I/O 能力**（不能使用 GPIO 34/35/36/39 等纯输入引脚）。
  - GPIO 4 不受开机 Strapping 引脚逻辑约束，开机无高频脉冲干扰，非常干净。
- **硬件要求**：
  - 必须在 GPIO 4（DQ 数据线）与 3.3V 电源之间并联一个 **4.7kΩ 的上拉电阻**。

## 4. 8 路 MOS 管驱动规范

### 4.1 驱动特性与电平逻辑
- **驱动类型**：低边开关（Low-Side Switch），采用 60V $V_{DS}$ N 沟道功率 MOS 管。
- **控制逻辑**：
  - **高电平（1 / 3.3V）**：MOS 管栅极建立导通电压，源漏极导通，回路接通（**开启 ON**）。
  - **低电平（0 / 0V）**：MOS 管栅极电荷泄放，源漏极截止，回路关断（**关闭 OFF**）。
- **继电器替换映射**：
  - 原 `relay_v2` 中的单一继电器控制逻辑由 **MOS1 (GPIO 19)** 完整承载。
  - 业务控制命令（如浇水持续时间、手动/远程开关）均直接操作 GPIO 19。
- **上电保护规范**：
  - 系统启动时，主控必须在配置 GPIO 方向前，先通过软件/硬件下拉将 MOS1~MOS8 设为低电平，避免上电浮空期间 MOS 管短暂误导通。

## 5. 剩余可用 GPIO 资源清单与扩展建议

除去 MOS 1~8、LED、按键、I2C、ADC1、DS18B20、串口及内部 Flash 之后，排针上剩余的 GPIO 资源整理如下：

### 5.1 纯输入引脚 (GPI - 仅支持输入/ADC1)
> **注意**：此类引脚内部无上拉/下拉电阻，无法输出电平，不能用于数字输出或 I2C/1-Wire。

| 引脚编号 | 硬件特性 | 推荐扩展用途 |
| :--- | :--- | :--- |
| **GPIO 35** | 模拟 ADC1_CH7 / RTC_GPIO5 | 额外模拟传感器（如光敏电阻、电位器、水位探测） |
| **GPIO 36 (SENSOR_VP)** | 模拟 ADC1_CH0 / RTC_GPIO0 | 额外模拟传感器或供电电压检测分压输入 |
| **GPIO 39 (SENSOR_VN)** | 模拟 ADC1_CH3 / RTC_GPIO3 | 额外模拟传感器或低功耗唤醒输入 |

### 5.2 安全无约束双向 GPIO (推荐优先使用)
> **注意**：无启动时序依赖，具备完整推挽/开漏输出与输入上拉/下拉能力。

| 引脚编号 | 硬件特性 | 推荐扩展用途 |
| :--- | :--- | :--- |
| **GPIO 32** | 双向通用 IO / ADC1_CH4 / Touch9 / RTC | 蜂鸣器、水流传感器脉冲计数、第二个 1-Wire 总线 |
| **GPIO 13** | 双向通用 IO / ADC2_CH4 / Touch4 / HSPI_MOSI | SPI 扩展屏幕、继电器扩展、通用数字输出 |
| **GPIO 14** | 双向通用 IO / ADC2_CH6 / Touch6 / HSPI_CLK | SPI 扩展时钟、通用数字输入中断 |

### 5.3 存在启动约束 (Strapping) 的 GPIO (谨慎使用)
> **注意**：此类引脚在芯片上电复位瞬间会采样外部电平作为芯片工作模式判断，外接电路不可干扰其开机电平！

| 引脚编号 | 约束类型与风险说明 | 扩展使用规范 |
| :--- | :--- | :--- |
| **GPIO 12** | **高危 Strapping (MTDI)**：复位瞬间若被外设拉高，芯片会将片内 Flash 供电设为 1.8V（当前模组为 3.3V Flash），**导致系统彻底崩溃无法启动**！ | **严禁外部接强上拉！** 仅可在确保开机为悬空或接下拉电阻时，作为普通输出使用。 |
| **GPIO 2** | **Strapping**：串口下载模式检测脚。芯片内部带弱下拉。若外部接强上拉可能影响串口固件烧录。 | 适合接普通指示灯（低电平点亮）或开机悬空的外设。 |
| **GPIO 5** | **Strapping (SDIO 时序)**：开机复位阶段会有瞬态高电平/PWM 脉冲。 | 勿接灵敏继电器或功率开关，可作为普通通信引脚。 |
| **GPIO 15** | **Strapping (MTDO/调试日志输出)**：开机阶段会持续输出高频调试时钟脉冲。 | 勿接电机或扬声器驱动，可作一般输入或非敏感输出。 |

## 6. 从 relay_v2 迁移到该硬件的核心代码映射指引

在将 `relay_v2` 代码复制并适配到本硬件工程时，需修改的主要宏定义对比如下：

```c
/* ======================== 硬件引脚映射变更 ======================== */

// 1. 继电器与 MOS 管控制
// 原 relay_v2:
// #define RELAY_PIN   4
// 现 ESPWROM32-4M-8xMOS:
#define MOS1_PIN        19  /* 替换原继电器控制引脚 */
#define MOS2_PIN        18
#define MOS3_PIN        17
#define MOS4_PIN        16
#define MOS5_PIN        33
#define MOS6_PIN        25
#define MOS7_PIN        26
#define MOS8_PIN        27

// 2. 指示灯与按键
// 原 relay_v2: #define BUTTON_PIN 9, #define LED_PIN 3
// 现 ESPWROM32-4M-8xMOS:
#define BUTTON_PIN      0   /* 板载 Key / Boot 键 */
#define LED_PIN         23  /* 板载用户 LED */

// 3. 传感器引脚
// 原 relay_v2:
// #define ADC_PIN_LOW_HUMIDITY  ADC_CHANNEL_0  /* ESP32-C3 GPIO0 */
// #define DS18B20_PIN           GPIO_NUM_1     /* ESP32-C3 GPIO1 */
// #define BH1750_SCL_IO         GPIO_NUM_6     /* ESP32-C3 GPIO6 */
// #define BH1750_SDA_IO         GPIO_NUM_7     /* ESP32-C3 GPIO7 */
//
// 现 ESPWROM32-4M-8xMOS:
#define ADC_PIN_LOW_HUMIDITY  ADC_CHANNEL_6  /* ESP32 GPIO34 (ADC1_CH6) */
#define DS18B20_PIN           GPIO_NUM_4     /* ESP32 GPIO4 */
#define BH1750_SCL_IO         GPIO_NUM_22    /* ESP32 默认 I2C SCL */
#define BH1750_SDA_IO         GPIO_NUM_21    /* ESP32 默认 I2C SDA */

// 4. 构建配置 (sdkconfig.defaults) 调整
// CONFIG_IDF_TARGET="esp32"                 /* 替换原 esp32c3 */
// CONFIG_ESPTOOLPY_FLASHSIZE_4MB=y
```
